# 自动化测试分级与黄金回归基准说明

1. **静态门禁层（Stage 1）**：`python3 tools/regression/scan.py all` 扫描后端 `NP-R01` ~ `NP-R10` 与前端 `FE-R01` ~ `FE-R13`，违规数必须等于 0。
2. **单元契约层（Stage 2）**：JUnit 5 + Vitest 覆盖时间换算、带种子概率分布、四层过程树递归清理、孪生锁速、一次性暂停、不可变批次落库、四类环检测、ECJ/javac 双编译一致性、水位线增量保存。
3. **黄金回归与确定性层（Stage 3）**：运行 `R1` ~ `R14` 共 14 个标准黄金用例；相同随机种子连续运行 3 次最终 `WorldSnapshot` SHA-256 必须 100% 一致；第 300 步存档重载续跑至第 1000 步结果与直跑 1000 步摘要 100% 一致。
4. **韧性与容量压测层（Stage 4）**：覆盖慢客户端 50kbps 限速不涨内存、千模型并发驻留内存 < 2.5GB、持久层故障注入恢复不丢数及长稳浸泡（Soak Test）零句柄泄漏。
